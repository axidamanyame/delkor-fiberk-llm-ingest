Fiberkapp.com — technical training map

Britsoft Sales and Inventory Advanced (Ultimate POS v6) at fiberkapp.com, business title DELKOR II FIBERK. Layout and functions only. Live stock, customers, and amounts are not copied here.

Each control below does at least three jobs: open (list or modal), change (edit / status / payment), leave a record (print, notify, or stock movement).

0. Shell

Black left rail. Active group is a purple chip. Main canvas is grey. Work sits in white cards. List pages share one schematic:

  1. Page title
  2. Filters card (funnel) — closed until opened on some desks, open on All sales
  3. List card — Show N entries, Export CSV / Excel / Print / Column visibility / PDF, Search
  4. Blue header DataTable, first column usually Action (except Products: checkbox, image, then Action)
  5. Teal outline Actions ▾ dropdown
  6. View = Bootstrap modal-xl fragment. Edit / Add = full page form.

Top quick-adds (every page footer/header): Add Sale, Add Purchase, Add Product, Add Expense, Add Stock Transfer, Add Stock Adjustment, Add Draft, Add Quotation.

Code on their side: Laravel + DataTables serverSide + product.js / module JS. List AJAX is often the same URL as the page (GET /products, GET /sells, GET /purchases) with X-Requested-With: XMLHttpRequest.

1. Home

/home — KPI tiles (Total Sales and siblings), location switcher, date filter, clock in/out modal, calculator, notifications. Three jobs: show period totals, switch business location, open POS / today’s profit.

5. Manufacturing

/manufacturing/recipe — recipes that turn components into a finished SKU. Three jobs: define recipe, produce a batch (consume components), see finished stock.

6. Repair

/repair/dashboard — job sheets and repair invoices. Three jobs: open job, bill parts/labour, hand device back.

7. Stock Transfers

List columns: Date, Reference No, Location (From), Location (To), Status, Shipping Charges, Total Amount, Additional Notes, Action.

Add form: Date*, Ref, Status*, From*, To*, product lines, shipping, notes. Three jobs: create pending transfer, mark in-transit / completed (stock leaves From, lands To), print.

8. Stock Adjustment

Add form: Location*, Ref, Date*, Adjustment type* (normal / abnormal), amount recovered, reason, product lines. Three jobs: write qty delta, optionally recover value, leave an audit row.

10. User Management

Users columns: Username, Name, Role, Email, Action. Roles define permission keys. Sales Commission Agents get a % on sales. Three jobs each: create login, attach role/locations, disable.

11. Expenses

Add: Location, category/sub, ref, date, expense-for, document, tax, total*, note, refund flag, recurring, payment block. List + Add + Categories. Three jobs: post cost, pay it, report it.

12. Payment Accounts

List: Name, Account Type, Sub Type, Account Number, Note, Balance, details, Added By, Action. Reports: Balance Sheet, Trial Balance, Cash Flow, Payment Account Report. Three jobs: hold a cash/bank/MoMo pot, receive a payment, move between pots.

13. Accounting (pages opened)

Dashboard, Chart of accounts, Journal Entry, Transfer, Transactions, Budget, Reports, Settings. Payment Accounts: List, Balance Sheet, Trial Balance, Cash Flow, Payment Account Report.

  • Dashboard: Account Type · Current Balance.
  • Chart of accounts: Tree/Tabular. Add = modal create_account_modal.
  • Journal: Action · Journal Date · Reference No · Added By · notes. Add = new page /journal-entry/create. Filter refreshes the table.
  • Transfer: Add = modal create_transfer_modal.
  • Transactions: Action-first sale-style grid.

13b. HRM (pages opened)

Dashboard, Leave Type, Leave, Attendance, Payroll, Holiday, Sales Targets, Settings, My Payrolls. Add Leave / status / payroll / attendance = modals on the same page.

  • Leave: Reference No · Leave Type · Employee · Date · Reason · Status · Action
  • Leave Type: Leave Type · Max Leave Count · Action
  • Holiday: Name · Date · Business Location · Note · Action
  • Attendance: Date · Employee · Clock In · Clock Out · duration · shift · Action
  • Payroll: Employee · Department · Designation · Month/Year · Ref · Total · Payment Status · Action

Our HRM tabs stay on /hrm.html?tab=. Leave/holiday/attendance headers now match the live lists.

14. Reports

Profit/Loss, Purchase & Sale, Tax, Supplier & Customer, Customer Groups, Stock, Stock Adjustment, Trending Products, Items, Product Purchase, Product Sell, Purchase Payment, Sell Payment, Expense, Register, Sales Representative, Service Staff, Activity Log. Each report: pick filters → render table → export.

15. Orders

/modules/orders — e-commerce / connector order inbox. Three jobs: list inbound orders, accept into a sale, reject / map customer.

16. Notification Templates

Email/SMS bodies for new sale, items received, payment, etc. Actions on lists call /notification/get-template/{id}/{key} in a modal. Three jobs: edit template, preview, send.

17. Settings

/business/settings — Business Name, start date, default profit %, currency, symbol placement, timezone, logo, financial year start, stock accounting method, transaction edit days, date/time format, currency/qty precision, plus invoice schemes, locations, barcodes, printers, tax rates, types of service, package subscription.

18. CRM · Project · Asset Management · HRM · Communications · Spreadsheet

  • CRM /crm/dashboard — follow-ups, sources, life stages, conversion. Schedule / complete / cancel a follow-up.
  • Project /project/project — projects, tasks, categories.
  • Assets /asset/dashboard — categories, allocated to you, warranty status. Allocate / revoke / maintain.
  • HRM /hrm/dashboard — people, leave, attendance, payroll.
  • Communications /communications.html — floor, announcements, messages, calls, meetings, groups, to-do, documents, memos, reminders, knowledge base.
  • Spreadsheet /spreadsheet/sheets — in-app sheets (not Excel files on disk).

IT notes for the Delkor ERP clone

  1. Do not copy Fiberkapp rows. Clone schematic: rail order, filter card, Action pill, modal View vs page Edit.
  2. Products custom field headers (SUPPLIERS…JIJI) are business-defined labels on product_custom_field1..7.
  3. View endpoints return HTML fragments (modal-dialog modal-xl), not full layouts.
  4. Our maps: List Products → /products.html; All sales → /pos-sales.html; List Purchases → /purchase-orders.html; Settings → /settings.html.
  5. Delkor-only rail after Spreadsheet: User Manual, Communication, Operations Hub, Collections, Field Ops, WMS. Those are not Fiberkapp pages.
